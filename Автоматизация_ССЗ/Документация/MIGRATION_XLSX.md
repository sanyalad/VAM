# Переход графиков ППР на формат .xlsx



## Зачем



Файлы `.xlsx` читаются через openpyxl за секунды. При включённом **`xlsx_com_hybrid`** (по умолчанию `true` в `config.json`) для кандидатов-ППР дополнительно проверяется заливка через Excel COM — как для старых `.xls`, но только по ячейкам плана, не по всему листу.



## Шаги



1. Откройте каждый `.xls` в Excel → **Файл → Сохранить как → Книга Excel (.xlsx)**.

2. Убедитесь, что розовые (отменённые) ячейки в плане видны так же, как в `.xls`.

3. Переименуйте старый файл в `*.xls.bak` или перенесите в `Графики/_archive_xls/`.

4. В приложении: **Анализировать графики** на один день — сравните число ППР и «Пропущено закрашенных».

5. Запустите массовую генерацию на 3–5 дней — при `xlsx_com_hybrid` в прогрессе может кратко появляться «Цвета Excel: …» (проверка .xlsx).



## Сверка xls vs xlsx (опционально)



Пара файлов:



```text

python tools/color_audit.py "Графики/файл.xls" "Графики/файл.xlsx" 6

```



Только папка `Графики` (как в приложении, с `xlsx_com_hybrid`):



```text

python tools/color_audit.py 6

```



Отчёт сохранится в `color_audit.txt`. В выводе: `openpyxl_colored`, `com_colored_added`, `colored_skipped total`.



## Если закрашенных 0 или меньше, чем в .xls



1. Убедитесь, что в `config.json` включено `"xlsx_com_hybrid": true` (или временно `"xlsx_com_fallback": true`).

2. Сохраните `.xlsx` с **явной** заливкой ячеек (не только условное форматирование).

3. Запустите `tools/color_audit.py` и сравните `only in xls` / `only in xlsx`.

4. Оставьте `.xls` в архиве — программа поддерживает его как запасной вариант.



## Настройки (`config.json`)



| Параметр | По умолчанию | Назначение |

|----------|--------------|------------|

| `xlsx_com_hybrid` | `false` | COM для .xlsx (медленно; включайте только при необходимости) |
| `com_skip_display_format_xlsx` | `true` | без DisplayFormat для .xlsx (быстрее COM) |
| `com_file_timeout_s` | `90` | таймаут COM на один файл |
| `bulk_extra_autosave_s` | `20` | автосохранение доп. заданий в массовой генерации |

| `xlsx_com_fallback` | `false` | только COM (медленнее, без openpyxl-фильтра) |

| `prefer_xlsx` | `true` | при паре .xls/.xlsx читается .xlsx |



## Кэш



`Кэш_цветов_графиков.json` привязан к пути файла — записи для `.xls` не мешают `.xlsx`.
